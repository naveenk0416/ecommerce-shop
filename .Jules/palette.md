## 2025-02-23 - Keyboard Accessibility for Hover-Revealed UI Elements
**Learning:** In Tailwind CSS, patterns like `opacity-0 group-hover:opacity-100` hide elements visually but often fail to appear when navigating via keyboard (e.g., using Tab). If these elements are interactive (like buttons or links), users relying on keyboard navigation won't be able to see where their focus is or what actions are available.
**Action:** Always pair `group-hover:opacity-100` with focus-aware classes. Use `group-focus-within:opacity-100` on parent containers when inner interactive elements need to trigger the reveal on focus, or use `focus-visible:opacity-100` directly on the focusable element. The same principle applies to transform utilities like `group-hover:translate-x-0`. This ensures interactive elements are visible for all users.
