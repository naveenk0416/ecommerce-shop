## 2024-05-24 - Async Button Loading States\n**Learning:** Users lack feedback when submitting forms like the "Log a Sale" modal, which can lead to multiple clicks and duplicate submissions. Native button disabled states are insufficient without a visual indicator of processing.\n**Action:** For critical async actions (e.g., form submissions in modals), use an Angular signal (`isSubmitting`) to manage loading states. Disable the submission button and display an `<ion-spinner>` while processing.
